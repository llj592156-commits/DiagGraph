# 设备手册父子分块接入

父子分块已作为 H / parent_child 与现有策略并列接入上传和现有流水线。当前实现、使用步骤及边界以 [父子分块系统接入说明](ParentChildSystemIntegration-zh.md) 为准；本轮仅接入分块和父块回查，图谱优化后续再加。

用户上传 PDF 时可选择“父子分块 · 设备手册（H）”。系统复用共享整理模块，读取书签、对齐 Docling 块、组织父块、切分子块，并保存到当前知识库的 full_docs / text_chunks / chunks_vdb。检索命中子块后回查父块，不建立独立实验知识库。

范围规则保持不变：文件名型号是父块默认范围，只有明确整个父块的限制才缩小；局部按钮、表格或脚注限制随证据保存，不缩小整个父块。未知与冲突保留为元数据，不当作通用适用。本轮不把这些元数据作为图谱硬过滤或消歧规则。

共享整理 API 和离线入口继续保留，见 [离线父子块说明](ParentChildOfflinePreparation-zh.md)。三份手册的版式规则属于已复核特例，新文档仍需查看结构审阅事项；不能承诺对所有 PDF 自动恢复正确层级。

原始 PDF、解析产物、历史实验和已有知识库均保留。已有已处理文档不会自动转换为 H，也不在本轮重新调用模型或重建索引。
